# AI-Powered Resume Analyzer

An AI-powered web application that allows users to upload their resume and receive detailed feedback on missing skills, weak sections, improvement suggestions, and job-readiness score. The system analyzes the uploaded CV using an AI API and generates a downloadable PDF report.

## Features

* Resume upload support
* AI-based CV analysis
* Skill gap detection
* Personalized improvement suggestions
* Job-readiness scoring
* Downloadable PDF report
* Clean and user-friendly interface

## Tech Stack

* Frontend: React / Next.js
* Backend: Node.js / Express
* AI: OpenAI API
* File Handling: PDF parsing and upload system
* Report Generation: PDF generator
* Deployment: Vercel / Render
